# Derril Water Solar Park

Home Assistant custom integration starter for a solar farm project.

This repository has been reset to a minimal baseline so you can build a new
solar-focused integration from scratch.

## Included starter functionality

1. Basic config flow (API key + site name)
2. Core setup/unload integration wiring
3. One starter sensor confirming setup status

## Integration identity

- Name: Derril Water Solar Park
- Domain: `derril_water_solar_park`
- Platform: `sensor`
