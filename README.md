# Derril Water Solar Park
⚠️ This repository is a minimal baseline for Derril Water Solar Parm when it's API comes online

Home Assistant hacs GitHub GitHub Copilot

Home Assistant custom componant for Derril Water Solar Parm



Not affiliated with Kirk Hill Co-op. This is a community integration that reads the dashboard's public API endpoints with your personal API key.

It pulls current data for both OpenAPI scopes:

owner (your ownership share)
site (whole-site values)

3. One starter sensor confirming setup status
